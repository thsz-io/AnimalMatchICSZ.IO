# Animal Match — Sistema de Adoção Responsável

O Animal Match é um sistema de adoção responsável que busca conectar animais a adotantes com base na compatibilidade entre suas necessidades e o estilo de vida do candidato, evitando decisões por impulso e critérios estéticos.

## Tecnologias
- React 18 e TypeScript
- Tailwind CSS v4
- Motion (Framer Motion)
- Lucide React
- React Router v7
- Radix UI

## Principais funcionalidades
- **Página inicial:** apresentação do sistema, animais disponíveis e filtros de busca.
- **Cadastro de adotantes:** formulário com dados pessoais, verificação de idade, informações sobre moradia e preferências.
- **Cadastro de animais:** registro de informações básicas, saúde e comportamento dos pets.
- **Dashboard do adotante:** visualização de compatibilidade e sugestões de animais.
- **Dashboard da ONG:** gerenciamento dos animais cadastrados e acompanhamento das solicitações.
- **Dossiê do animal:** histórico de saúde, interações, conversas e linha do tempo de eventos.

## Características principais
- Sistema de compatibilidade baseado no perfil do adotante e nas necessidades do animal.
- Interface responsiva e acessível, com animações e navegação intuitiva.
- Formulários com validação visual.
- Histórico de saúde e auditoria das interações.
- Dados simulados, sem integração com um backend real.

## Segurança e auditoria
O sistema prevê validação de idade, simulação de verificação de identidade, registro de informações de saúde e histórico de interações entre ONGs e candidatos.

## Status
Projeto acadêmico de Banco de Dados, desenvolvido para promover uma adoção de animais mais consciente, segura e responsável.
